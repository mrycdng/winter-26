thinking about thinking about thinking about

For Exercise 8, I only used ChatGPT to write another portion of JS to transform my Exercise 7 website. In Exercise 7, I conceived of a simple JS function which fills empty spans with a random word from my array, to create a sentence chain of people thinking about each other. In Exercise 8, I wanted to heighten the visual effect of the entangled relationships by having each thought span “float” somewhere onscreen, and a web of thin white lines connecting them to each other.

Because I have a moderate amount of knowledge in, I could understand mostly what ChatGPT was generating. For instance, I knew when it was generating random x + y coordinates to position each span, when it is drawing a line between each span, etc. However, the actual “thinking” and specifics behind the code itself is more advanced than what I could’ve come up with by myself.

At one point, it also took the initiative to code something I didn’t specifically prompt it to generate: to have each click re-randomize the span positions. This definitely makes the user experience more fun (they can now see it change without reloading the site), but it also brings to my attention how if I were to use it again, I’d need to go through the code just as thoroughly as this time to make sure it’s doing what I wanted it to. I’d also hesitate to use it to generate all of my HTML/CSS/JS for a project because its initiative limits my own creativity, and I might then have trouble understanding what it is doing. I find coding my own HTML structure with CSS styling, then some light JS generation to be a more workable model.
